# Summary (EN / [RU](summary_ru.md))

![](screenshot.png)

The **blue** plot displays a random analog signal. The **light green** plot displays a simplified analog signal that changes at a rate selected by the user. Like a capacitor charged or discharged at constant current, it changes linearly between its limits.

The thin green plot shows the user's three-level control signal: holding the left mouse button or touching the right half of the screen moves the light green plot upward; with no control held, it moves downward; holding the right mouse button or touching the left half of the screen makes it move downward twice as fast. The faster downward movement takes priority when both controls are held.

The goal of the game is to replicate the shape of the blue plot by the light green plot as close as possible.
