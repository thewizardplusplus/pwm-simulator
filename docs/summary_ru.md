# Краткое описание ([EN](summary.md) / RU)

[<< Назад](README_ru.md)

![](screenshot.png)

**Синий** график отображает случайный аналоговый сигнал. **Светло-зелёный** график отображает упрощённый аналоговый сигнал, скорость изменения которого выбирает игрок. Подобно напряжению конденсатора при зарядке или разрядке постоянным током, между предельными значениями он меняется линейно.

Тонкий зелёный график показывает трёхуровневый управляющий сигнал игрока: при удержании левой кнопки мыши или касании правой половины экрана светло-зелёный график идёт вверх; без нажатий он идёт вниз; при удержании правой кнопки мыши или касании левой половины экрана он идёт вниз вдвое быстрее. При одновременном удержании обоих действий приоритет имеет ускоренное движение вниз.

Цель игры: максимально точно повторить форму синего графика зелёным.
